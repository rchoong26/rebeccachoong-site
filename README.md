# Rebecca Choong Personal Brand Website V1

Premium one-page personal brand website for Rebecca Choong, built with Next.js, React, and Tailwind CSS.

## File Structure

```text
app/
  globals.css      Global Tailwind styles, animations, and biotech visual patterns
  layout.tsx       Metadata, fonts, and root layout
  page.tsx         One-page website sections and content
public/
  rebecca-hero.png Hero / portrait image used by the page
```

## Local Setup

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Deploy

This project is ready for Vercel. Push the folder to a Git repository, import it into Vercel, and use the default Next.js build settings.
